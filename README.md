# FastSocial

Plataforma white-label de automação de redes sociais: pesquisa de tendências, geração de copy e carrosséis com IA fiel à marca do cliente, agendamento/publicação multi-rede (Instagram, Facebook, LinkedIn) e piloto automático de ponta a ponta.

- **Plano do produto e arquitetura**: [`.prd/prd_autocontent_os.md`](.prd/prd_autocontent_os.md)
- **Specs executáveis (56, organizados em 11 fases)**: [`.specs/EXECUTAR-SPECS.md`](.specs/EXECUTAR-SPECS.md)
- **Como rodar o projeto (tudo no VPS, sem ambiente local)**: [`.specs/shared/como-executar.md`](.specs/shared/como-executar.md)
- **Checklist de acessos/contas necessárias**: [`.prd/checklist_acessos_e_delegacao.md`](.prd/checklist_acessos_e_delegacao.md)

Infraestrutura roda inteiramente no VPS Hostinger `N8N.volupia` (KVM 4), gerenciado via Easypanel, ao lado de outros serviços já existentes (n8n, Postiz, Cal.com).
